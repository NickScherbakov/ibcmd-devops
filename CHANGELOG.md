# Changelog

## 0.1.0 — 2026-09-23

- Первый публикационный прототип.
- Безопасный запуск ibcmd через массив аргументов.
- Dry-run, журналирование, редактирование секретов в командной строке.
- DT-образ, XML export/import, CF save/load/apply.
- Явные предохранители для операций, меняющих базу.
- Примеры ландшафта и политики будущего ИИ-робота.

### Известные ограничения

- Код не испытан авторами на полном наборе версий платформы и СУБД.
- Точное CLI проверяется командой `ibcmd ... --help` на целевой версии.
- Автоматизация chdbfl, проверка/исправление данных и ИИ-агент не реализованы.
