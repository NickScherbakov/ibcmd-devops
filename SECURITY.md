# Безопасность

- Не храните пароли, токены и серверные конфигурационные файлы с секретами в Git.
- Используйте secret store CI/CD, переменные окружения или корпоративное хранилище секретов.
- Передавайте секретные значения в `-SensitiveValues`, чтобы они не попадали в отображаемую команду и лог модуля.
- Помните: дочерний процесс теоретически может вывести чувствительные данные в stdout/stderr; проверяйте поведение вашей версии ibcmd.
- Не предоставляйте ИИ-агенту произвольный shell-доступ.
- Любые операции на PROD выполняйте только по утверждённому регламенту, с журналом, окном работ и планом отката.
- DT-выгрузка не заменяет штатное резервное копирование СУБД.
